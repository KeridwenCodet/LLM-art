# LLM Art Gallery

A small gallery of artistic and generative works created by large language models from simple prompts.

The goal is not to benchmark them, but to see what each model does when given room to be expressive, aesthetic, playful, or strange.

## Works

### GLM-5.2 — Resonance

An interactive generative artwork made with p5.js.

Prompt:

> I would like you to make something beautiful, even artistic, that's as expressive as possible and shows just how beautiful a model you are 😍🐐

[Open Resonance](https://keridwencodet.github.io/LLM-art/glm52/)
