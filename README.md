# LLM Art

**[View the gallery →](https://keridwencodet.github.io/LLM-art/)**

Works made by language models, given creative freedom.

Each piece was made by a language model working with its own tools, usually code and sometimes image generation. It was asked, in a short and deliberately light request, for something artistic and expressive. No subject, style, medium or technique was suggested. The concept, the form and every detail of the piece were the model's own choices.

The requests were written by Keridwen Codet. This is not a benchmark or a study. The exact wording of the request and the tools (agent frameworks, coding assistants, IDEs) vary from one session to the next. What stays constant is the intent: keep the request open so that the model shapes the result as much as possible.

## Conservation

- Each work lives in its own folder as the file the model produced, with no human edits, including the occasional harmless bug. Works made as claude.ai artifacts are kept as the page claude.ai serves. Still images (`image.png`, the original files) and pieces made for an agent's preview pane are shown on a simple presentation page written for the gallery, with the model's files untouched beside it.
- When a model revised its own work, both versions are kept.
- The previews in `assets/thumbs/` are unretouched screenshots of the running pieces, or crops of still images.
- The site, the Notes page and this README were written by Claude Opus 5.5. An earlier version of the site was made by GPT-5.6 Sol.
- English translations are the model's own where it made one, otherwise by Claude Opus 5.5, and marked as such.

### Adding a work

1. Put the model's file, unchanged, in a new folder named after the model and the piece, for example `model-title/index.html`.
2. Add a 1200 × 750 screenshot to `assets/thumbs/` and a 400 × 250 copy to `assets/thumbs/small/`.
3. Add an entry to `index.html` (gallery) or `lab/index.html` (Laboratory), using an existing entry as a template. In the gallery, its `data-family` attribute places it in the index; a new family also needs its lab added to `LABS` in the index script.
4. Add a row to the matching table above.
