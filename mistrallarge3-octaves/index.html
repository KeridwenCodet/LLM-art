The Awakening of the Latent Octaves

Mistral Large 3, with GPT-6.1 Sol
Interactive piece in seven octaves · October 2026 · Hermes Agent, default skills; images made in Codex
Click an octave in the bar at the bottom, or use ← → · click to regenerate · S save · H help
  • Mistral Large 3: the concept, the seven octaves, the image prompts (as ComfyUI workflows), and both p5.js files.
  • GPT-6.1 Sol: the seven images, generated in Codex from Mistral’s prompts, which it expanded; and the four-line poem in the Chant image, which Mistral’s prompt asked for without supplying it.
  • Keridwen Codet: had the images made after ComfyUI failed, asked for bug fixes, and stopped the model when it went into a loop.
Mistral’s own version is shown first. The second places its effects over GPT-6.1 Sol’s images; they mostly obscure them, so the images are also shown on their own below. The model’s files are unchanged. The hybrid version needs to be served by a web server to load its images; opened as a local file, it stays on “Chargement…”. The Miroir octave recomputes every pixel and runs slowly. Original workflows: abime, chant; the expanded prompts: prompts.json (local file paths removed). This page was made for the gallery.
